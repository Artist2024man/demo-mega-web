# Demo Mega Web

Vue 3 账号详情页面项目

## 功能特性

- 支持通过URL参数 `accountId` 获取账号信息
- 显示账号基本信息、持仓信息、运行中的会话
- 支持开始/停止策略操作
- 支持停止运行中的会话
- 响应式设计，适配手机端

## 安装依赖

```bash
npm install
```

## 开发运行

```bash
npm run dev
```

访问 `http://localhost:5173/?accountId=你的账号ID`

## 构建

```bash
npm run build
```

## 预览

```bash
npm run preview
```

## 技术栈

- Vue 3
- Vue Router
- Axios
- Vite
